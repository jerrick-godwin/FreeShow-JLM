# Release notes

## 1.0.0 — Initial ministry release

- Ministry branding, branch setup, and a seven-step first-launch walkthrough.
- Independent song and Bible layouts, including backgrounds and multi-translation displays.
- Live English, Sinhala, and Tamil Bible reference and text search.
- PDF, Word, CSV, and native imports with OCR, correction previews, duplicates, cancellation, and undo.
- Included church songbook, three Bibles, multilingual speech model, and OCR language data.
- Default-enabled suggestions and captions; operator-controlled listening and confirm-once live following.
- Pause/resume/stop, manual-navigation overrides, output locks, and data-preserving setup.
- Verified bundled-asset checks and native speech-runtime checks during packaging.

Live following is experimental. Singing with accompaniment, congregation noise, and representative Sinhala/Tamil recordings require further real-world validation. Optional online discovery requires internet access and operator review of lyrics.

Installer builds are unsigned. Windows and macOS may display publisher or security notices; signed/notarized distribution is not configured. Supported release targets are Windows x64, macOS Intel, and macOS Apple Silicon. Native build results and available downloads are listed on the GitHub release.
