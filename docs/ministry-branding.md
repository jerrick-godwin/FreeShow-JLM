# Ministry branding

The main window uses the supplied Jesus Lives logo and the name **Jesus Lives Evangelical International Ministry**, followed by the configured branch and “Branch”.

First-time setup requires a branch name. Existing installations can enter or change it under **Settings → General → Branch name**. Changes appear immediately in the header and are saved with the installation's settings. Until a branch is entered, the header says “Branch not set”.

The default UI palette samples the supplied logo: navy `#0E3B5E`, gold `#B8933A`, flame yellow `#FFC805`, and white. Darker navy surfaces and gold/yellow highlights keep controls readable. The previous built-in default palette migrates to these colours; separately created custom themes remain available.

The bundled logo is `public/branding/ministry-logo.png`, so the installed app does not depend on the original iCloud file. Branding applies to the operator UI; presentation slide text and backgrounds retain their existing settings.
